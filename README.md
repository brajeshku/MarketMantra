# MarketMantra UI

Responsive landing-page prototype for **Market Mantra WealthOrbit**, based on the supplied page image and the visual direction of harVVest. The current scope is front-end only.

## Stack

- Next.js App Router and React
- TypeScript
- Tailwind CSS 4
- shadcn/ui-style primitives with Radix UI Slot
- Lucide icons

## Run locally

Install Node.js 20.9 or newer and npm, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## UI-only notes

- Market figures are illustrative sample values, not live market data.
- The enquiry form displays a local confirmation and does not send or store submissions.
- Course names, durations, prices, contact details, and institute copy follow the supplied visual reference and should be reviewed before launch.
- No API, authentication, payment, advisory, or market-data integration is included.
